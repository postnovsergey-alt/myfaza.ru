# Как запустить всё это в VSCode

Инструкция для человека, который не пишет код сам. Делайте по порядку,
ничего не пропуская. Займёт 20–30 минут в первый раз.

---

## Что вам придётся сделать руками

Ровно два действия. Всё остальное разворачивает скрипт.

**Почему только эти два.** Claude Code нельзя установить агентом — нужен
работающий агент, чтобы его установить, а его ещё нет. Docker Desktop —
приложение с окном, его надо запустить и подтвердить запуск; скрипт умеет
его поставить и открыть, но нажать «Разрешить» в системном диалоге за вас
не может.

---

## Шаг 1. Поставить Claude Code

Откройте Терминал (Spotlight → «Терминал») и выполните:

```bash
npm install -g @anthropic-ai/claude-code
```

Если ответит «command not found: npm» — сначала поставьте Node.js
с [nodejs.org](https://nodejs.org), потом повторите.

---

## Шаг 2. Перенести файлы в вашу папку

Папка проекта у вас уже создана:

```
/Users/sergeypostnov/Documents/Программы созданные VS_CODE/myfaza.ru
```

⚠️ **В Терминале путь пишется `Documents`, а не `Документы`.** Finder
показывает русское название, но на диске папка называется по-английски.
Скопируете «Документы» — получите «No such file or directory».

### Проще всего — через Finder

Откройте две папки рядом: ту, где лежит готовый проект `myfaza`, и вашу
`myfaza.ru`. Выделите **всё содержимое** папки `myfaza` (⌘A) и перетащите
в `myfaza.ru`.

Важно: перенести нужно именно содержимое, а не саму папку `myfaza` внутрь.
Должно получиться `myfaza.ru/backend/`, а не `myfaza.ru/myfaza/backend/`.

Finder по умолчанию скрывает файлы, начинающиеся с точки, — а их в проекте
семь штук, и без них ничего не заработает. **Нажмите ⌘⇧. (Cmd + Shift +
точка)**, чтобы они стали видны, и только потом выделяйте.

### Или одной командой в Терминале

Надёжнее: `/.` в конце источника захватывает и скрытые файлы.

```bash
cp -R "<перетащите сюда папку myfaza>"/. "/Users/sergeypostnov/Documents/Программы созданные VS_CODE/myfaza.ru/"
```

Папку `myfaza` перетащите из Finder прямо в окно Терминала — путь
подставится сам, вместе с кавычками.

Проверьте, что всё на месте:

```bash
cd "/Users/sergeypostnov/Documents/Программы созданные VS_CODE/myfaza.ru"
ls -a
```

Должны быть видны `backend`, `docs`, `scripts`, `CLAUDE.md`, `.claude`,
`.vscode`, `.mcp.json`, `.env.example`, `.gitignore`, `docker-compose.yml`.

---

### Про пробелы и кириллицу в пути

Ваш путь содержит и то и другое. Работать будет, но:

- **Все команды с путями пишите в кавычках.** Без них терминал решит,
  что «Программы» и «созданные» — это два разных аргумента.
- Точка в имени `myfaza.ru` ломала бы Docker Compose: он берёт имя проекта
  из имени папки, а точка там запрещена. Уже исправлено — имя задано явно
  в `docker-compose.yml`.

Ничего переименовывать не нужно, всё учтено. Но если однажды захотите
перенести проект — путь без пробелов и кириллицы избавит от целого класса
мелких проблем.

## Шаг 3. Открыть в VSCode и сказать одну фразу

`Файл → Открыть папку` → `~/Projects/myfaza`.
На предложение установить рекомендованные расширения — согласитесь.

Откройте терминал внутри VSCode (`Терминал → Новый терминал`) и запустите
агента:

```bash
claude
```

Первый раз попросит войти через браузер. Дальше напишите ему:

```
/setup
```

**Всё.** Дальше он сделает сам:

- проверит и доустановит недостающие инструменты (git, Node, Docker)
- запустит Docker, если тот не запущен
- заведёт git-репозиторий и первый коммит
- сгенерирует все секреты и создаст `.env`
- положит копию секретов в `~/.myfaza-backup/`
- соберёт и поднимет контейнеры
- применит миграции
- прогонит тесты
- проверит, что API отвечает

Если что-то упадёт — починит и повторит. Остановится и скажет только там,
где без вас никак: запустить Docker Desktop, если он не установлен.

Когда закончит, напишет адрес: http://localhost:8000/api/docs

## Шаг 4. Работа по спринтам

В том же окне агента:

```
/sprint 2
```

Это спринт «Аутентификация» целиком. Агент разобьёт его на задачи, будет
делать их по очереди, гонять тесты и коммитить. Вмешиваться не надо.

Когда закончит — покажет отчёт. Дальше `/sprint 3` и так до шестого.

### Команды агента

| Команда | Что делает |
|---|---|
| `/setup` | Развернуть или починить окружение |
| `/sprint N` | Выполнить спринт N целиком |
| `/check` | Полная проверка: тесты, линтер, миграции, секреты |
| `/handoff` | Подвести итог сессии, записать состояние |
| `/clear` | Очистить контекст. Делайте между спринтами |
| `Esc` | Прервать агента, если пошёл не туда |

### Если не хочется терминала

`Терминал → Выполнить задачу` в меню VSCode — там кнопки: развернуть
окружение, запустить, остановить, применить миграции, прогнать тесты,
показать логи. То же самое, но мышкой.

## Про секреты

Скрипт генерирует их сам и кладёт копию в `~/.myfaza-backup/`.

⚠️ `FIELD_ENCRYPTION_KEY` шифрует заметки пользовательниц. **Потеряете —
расшифровать будет нечем, данные пропадут навсегда.** Скопируйте файл
из `~/.myfaza-backup/` куда-нибудь ещё: в менеджер паролей, на флешку.

`BOT_TOKEN` скрипт заполнить не может — его выдаёт @BotFather в Telegram.
Понадобится в спринте 2, агент напомнит и скажет, куда вставить.

---

## Что делать между спринтами

1. Прочитайте отчёт агента.
2. Загляните в `QUESTIONS.md` — там накопленные вопросы к вам.
3. Ответьте на них прямо в чате агента.
4. `/clear`, потом `/sprint N+1`.

Файл `PROGRESS.md` всегда показывает, где вы находитесь. Если забыли —
откройте его.

---

## Насколько агент самостоятелен

Настроен так, чтобы не дёргать вас по пустякам. Подробности —
в `docs/AGENT-PROTOCOL.md`, если коротко:

**Делает сам, не спрашивая:** пишет и правит код, создаёт файлы, гоняет
тесты, поднимает и перезапускает контейнеры, создаёт миграции, коммитит,
чинит свои же баги.

**Делает сам, но записывает в `DECISIONS.md`:** добавляет библиотеку,
отклоняется от ТЗ в мелочи, меняет схему БД внутри спринта. Вы можете
прочитать и возразить постфактум.

**Останавливается и спрашивает:** секреты и ключи, что-либо платное,
продакшен, удаление пользовательских данных, юридические тексты, смена
домена. Всё остальное — не ваша забота.

**Если застрял:** три попытки, потом ищет в документации, потом обходит
заглушкой, пишет вопрос в `QUESTIONS.md` и идёт дальше по списку задач.
Не зависает в ожидании вас.

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| `make up` падает | Проверьте, запущен ли Docker Desktop |
| «порт 5432 занят» | На машине уже крутится Postgres. Скажите агенту — поменяет порт |
| Агент просит разрешение на каждую команду | Проверьте, что файл `.claude/settings.json` на месте, перезапустите `claude` |
| Агент делает не то | `Esc`, затем объясните словами, что не так |
| Всё сломалось | `git status`, `git checkout .` — откатит несохранённые правки |
| Забыли, где остановились | Откройте `PROGRESS.md` |

Отдельно: **не редактируйте код руками**, если не уверены. Скажите агенту
словами, что хотите изменить, — он сделает и прогонит тесты.

---

## Чего делать нельзя

- Коммитить `.env` (он в `.gitignore`, но всё же)
- Менять домен `myfaza.ru` после того, как запустите сайт в проде —
  сломаются push-уведомления у всех, кто уже установил приложение
- Выкладывать в продакшен без ответа на вопросы из раздела 16 ТЗ:
  оператор ПДн, уведомление Роскомнадзора, политика конфиденциальности
