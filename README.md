# Моя фаза

Трекер менструального цикла: Telegram Mini App + бот и веб-версия (PWA) на одном бэкенде.

- **Домен:** myfaza.ru
- **Бот:** [@moyafaza_bot](https://t.me/moyafaza_bot)
- **ТЗ:** [CLAUDE.md](./CLAUDE.md) — полная спецификация, она же контекст для AI-агента в VSCode

## Первый раз здесь?

Откройте **[docs/START-HERE.md](./docs/START-HERE.md)** — пошаговая инструкция
по запуску в VSCode, от установки Docker до команды `/sprint 2`.

## Запуск

```bash
claude      # затем в агенте:  /setup
```

Одна команда разворачивает всё: инструменты, git, секреты, контейнеры,
миграции, тесты. Без агента — то же самое напрямую:

```bash
bash scripts/setup.sh
```

Проверка: http://localhost:8000/api/v1/health/ready

## Что уже сделано (спринт 1)

- Каркас FastAPI, конфиг на pydantic-settings
- Все 9 моделей БД из раздела 6 ТЗ + начальная миграция

## Важно знать до старта

**Домен менять нельзя.** VAPID-ключи Web Push и установленные PWA привязаны к origin. Смена домена после запуска молча обнулит все подписки на уведомления.

**Данные о цикле — специальная категория ПДн** (ст. 10 152-ФЗ). Отсюда требования: отдельное согласие, хранение в РФ, шифрование, никакой сторонней аналитики на страницах с данными, никаких дат и симптомов в логах. Подробности — раздел 11 ТЗ.
